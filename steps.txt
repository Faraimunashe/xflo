## Project Overview

**Xflo** is a Laravel 12 application for building a school accounting capture and reporting system for "Paradise International School".

### Current State
- Fresh Laravel 12 installation
- Inertia.js with Vue 3
- Tailwind CSS v4
- Vue3 Snackbar for notifications
- Font Awesome icons
- SQLite database (default; MySQL supported)
- Basic authentication (User model exists)
- No accounting functionality yet

### Architecture
- Backend: Laravel 12 (PHP 8.2+)
- Frontend: Vue 3 + Inertia.js
- Styling: Tailwind CSS v4
- Database: SQLite (configurable to MySQL)

### Project Structure

```
/app
  /Http
    /Controllers - Only base Controller.php exists
    /Middleware - HandleInertiaRequests.php configured
  /Models - Only User.php exists
  /Providers - AppServiceProvider.php
/routes
  web.php - Only default welcome route
/resources
  /js/app.js - Inertia + Vue 3 setup
  /views/app.blade.php - Inertia root template
```

### Planned Features (from prompt.txt)

1. Three core database tables:
   - `accounts` - Chart of accounts
   - `journal_entries` - Accounting entries
   - `journal_lines` - Entry line items

2. Double-entry accounting:
   - Debits must equal credits
   - Draft and Posted statuses
   - Reversal entries for corrections

3. Reports:
   - Account statement (ledger) with running balance
   - Trial balance
   - Income statement
   - Balance sheet
   - Cash flow statement (direct method)

4. UI requirements:
   - Top navigation only
   - Reusable Vue components
   - Interactive feedback (validation, totals, toasts)
   - Searchable dropdowns using vue-multiselect
